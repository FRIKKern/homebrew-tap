# FRIKKern/homebrew-tap

| Formula | What |
|---------|------|
| [minmacs](https://github.com/FRIKKern/minmacs) | Menu bar app and CLI that reclaims CPU and RAM for developers and agents. `brew install frikkern/tap/minmacs` |
| [insomnia](https://github.com/FRIKKern/insomnia) | Menu bar app that keeps your Mac awake, with lid-closed mode and guards. `brew install frikkern/tap/insomnia` |
| [noo-noo](https://github.com/FRIKKern/noo-noo) | A smart, opt-in cleanup daemon for Mac developers |

## noo-noo

## Install

```sh
brew tap FRIKKern/tap
brew install noo-noo
```

For the headless CLI-only Formula:

```sh
brew install --formula FRIKKern/tap/noo-noo
```

Casks and Formulae are kept in sync by the
[noo-noo release workflow](https://github.com/FRIKKern/noo-noo/actions/workflows/release.yml).
